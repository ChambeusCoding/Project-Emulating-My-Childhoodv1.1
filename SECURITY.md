Reporting a Vulnerability

If you discover a security vulnerability, we appreciate your help in responsibly disclosing it so we can address it quickly.

To report a vulnerability:

    Email us at jwchambers00@protonmail.com with the subject line “Vulnerability Report”.

    Please include as much information as possible, such as:

        Steps to reproduce the issue.

        The potential impact (e.g., data exposure, privilege escalation).

        Any suggested fixes or mitigations.

Response timeline:

    We will acknowledge receipt of your report within whenever I look at my email.

    If the vulnerability is accepted, we’ll coordinate a fix and announce it in the next security release.

    If the report is declined, we’ll explain why and offer feedback where possible.

We kindly ask that you do not publicly disclose the vulnerability until a fix has been released and confirmed.
